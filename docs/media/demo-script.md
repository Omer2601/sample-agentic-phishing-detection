# Demo video script

The script of the [demo video](demo.mp4) (captions: [demo.srt](demo.srt)), about 2 minutes 15 seconds. Use it to present the sample live with the same flow. Every number in it is measured; the source is [evaluation.md](../evaluation.md#latency-flags-on-by-default-2026-11-03). The phishing examples were scanned in the app before recording; the video only shows the app's own result pages, never a phishing site itself.

| #   | Scene              | On screen                                                                  | Narration                                                                                                                                                                                                                                                                                                                                                                                            |
| --- | ------------------ | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | The problem        | Title card                                                                 | Every day, people report suspicious links, and platforms have to decide whether a link is safe to publish. Checking each one by hand is slow. This sample triages a link in about twenty seconds, with the evidence a person needs to make the call.                                                                                                                                                 |
| 2   | How it works       | Architecture diagram                                                       | It runs in your own AWS account. When you submit a URL, three specialist agents on Amazon Bedrock AgentCore start at the same time: one checks the link and its domain, one looks at the page, and one reads the page's code. The page opens in AgentCore Browser, an isolated browser that AWS runs, never on your machine. An orchestrator agent then weighs their findings and gives the verdict. |
| 3   | A live scan        | Sign in, scan a legitimate URL, verdict appears                            | Let's scan a well-known page. The app shows each agent's progress, and the verdict arrives first: legitimate, low risk, allow. The full report follows a few seconds later.                                                                                                                                                                                                                          |
| 4   | A phishing verdict | A stored phishing result: verdict, specialist evidence, screenshot, report | Here is a link from a public phishing feed. Verdict: phishing, high risk, block. All three specialists agree: a look-alike of a gaming site's domain, a copied profile page, and sign-in buttons that load a cloned login page from the same host. The screenshot was taken in the isolated browser, and the report explains the decision in plain language. Every verdict is advisory, so a person makes the final call.         |
| 5   | Many URLs at once  | A completed batch                                                          | You can upload a CSV of up to two hundred URLs in the app, or up to a thousand through the API. Each URL gets its own verdict, risk, time and cost. Dead links and pages that answer 404 get a fixed answer without an orchestrator call.                                                                                                                                                            |
| 6   | The API            | Terminal: submit a scan, poll, read the verdict                            | The same API powers the app. Every call is signed with AWS SigV4. A publish flow can submit a URL, wait for the verdict, and hold anything risky for review.                                                                                                                                                                                                                                         |
| 7   | Measured results   | Results table                                                              | We measured the default on four hundred and seven live URLs. It caught eighty eight percent of the phishing links, with a false positive rate under five percent. The median scan took under nineteen seconds, at nine cents of model cost per scan, about half the time and a third less cost than the previous design.                                                                             |
| 8   | Clean up           | The destroy command                                                        | One command deploys it, and one command removes it. Clone the repository, follow the getting started guide, and scan your first link in minutes.                                                                                                                                                                                                                                                     |

## Recording notes

- Recorded on a separate test copy of the stack (`-c appName=demo`) with a demo user whose email is not a real person's, at 1920 by 1080, with Playwright; narration is Amazon Polly (neural voice); scenes are joined with ffmpeg.
- No account id, internal tool or personal email appears on screen. The API scene shows `$API` instead of the endpoint.
- The demo stack was destroyed after recording.
