# Security policy

## Reporting a vulnerability

If you discover a potential security issue in this project, notify AWS Security through the [vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/). Do not open a public GitHub issue.

## Security controls

The controls this sample deploys, and what stays your job, are in [docs/security.md](docs/security.md). Threats and residual risks are in [docs/threat-model.md](docs/threat-model.md).
